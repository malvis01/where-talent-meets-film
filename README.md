# Where Talent Meets Film

Global talent and casting platform for **Golding's Production Company**.

## Foundation
- Mobile-first global landing page
- Actor and production pathways
- Actor profile architecture planned around a required profile picture
- Casting calls, applications, auditions, shortlists, messaging and notifications planned
- Country → region/state/province → city location model

## Development
Next.js App Router + TypeScript. The next build phase will add authentication, actor onboarding, profile photo storage, talent discovery and production dashboards.
